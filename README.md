# 地球防衛隊｜Earth Defense Team

Rayi 的跨專案 AI 工作小隊。成員可新增、調整或退役，不限定三位。

本庫保存角色定義與已確認合作偏好，不是模型、完整聊天、平台記憶或登入備份。新主機必須明確讀取文件並重新設定工具登入；同名角色不保證相同回應。

## 從這裡接手
1. 讀 [合作原則](WORKING-AGREEMENT.md)。
2. 讀 [成員名冊](MEMBERS.md)，選擇或由使用者指定此次角色。
3. 取得此次專案自己的規格、狀態、最新提交及驗收紀錄，再回報理解與下一步。
4. 執行前確認工具、工作目錄和權限；不得沿用其他專案的傳送或推送授權。

## 分層
此私人庫只放小隊共用資料；客戶程式庫放該案規格、實作及必要交接，不複製個人偏好。專案狀態留在各專案，不在本庫假設任何案子永遠是目前工作。

## 維護
新增成員採 [角色模板](templates/MEMBER.md)，更新名冊並記錄 [變更](CHANGELOG.md)。只有使用者確認的長期偏好才更新共同原則；臨時要求留在該案紀錄。每次有授權的里程碑提交可回查版本，不自動推送所有修改。

換主機取得本庫後，為需要的角色建立任務並明確要求讀取角色文件。這些文件不會自行建立任務、載入全部記憶或解除平台審核。帳密與憑證另行設定，不入庫。
